# APEX SENTINEL — Project Record

**Owner:** Apex Global LLC  
**Product:** APEX SENTINEL  
**Architecture:** Manifest V3 browser extension  
**Patent reference:** USPTO provisional 63/940,186

## Trinity

### SHIELD
DeclarativeNetRequest rules block known advertising and analytics endpoints. The current project rule set contains 54 explicit rules.

### AURA
A conservative dark theme is injected locally. Site-specific state can override the global preference.

### CLEANSE
Known campaign and click identifiers are removed from URLs and anchor links before navigation where the content script can observe them.
