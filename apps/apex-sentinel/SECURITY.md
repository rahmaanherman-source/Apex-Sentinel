# Security Policy

## Scope

Report vulnerabilities affecting APEX SENTINEL, including extension privilege escalation, unsafe request handling, tracking-data leakage, malicious rule injection, or supply-chain issues.

## Reporting

Do not publish sensitive exploit details before remediation. Contact Apex Global LLC through its established private security channel and include affected version, browser/version, reproduction steps, and impact.

## Security principles

- Least-privilege extension permissions.
- No remote executable code.
- No telemetry by default.
- No secrets in source, logs, or extension storage.
- Declarative request rules preferred over blocking JavaScript listeners.
